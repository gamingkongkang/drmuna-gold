# Muna Gold Test Site

This is a simple static website prepared for a first GitHub -> Cloudflare deployment test.

Recommended repository structure:

muna-gold-test/
├── public/
│   └── index.html
└── README.md

Cloudflare Pages test settings:
- Production branch: main
- Framework preset: None
- Build command: exit 0
- Build output directory: public

After deployment, Cloudflare should provide a *.pages.dev URL.
